# Learning Architecture

Learning architecture is the method behind a credential that means something. This interactive page walks through how content becomes capability a learner can prove, across six phases, Explore, Classify, Write, Validate, Evaluate, and Improve, and four levels of growth, Foundation, Technician, Administrator, and Expert. Built as a clean left-navigation experience with HTML, CSS, and JavaScript. A reusable, brand-independent framework for designing certifications that hold up.
